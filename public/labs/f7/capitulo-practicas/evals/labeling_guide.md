# Guía de etiquetado

La respuesta pasa si ayuda al alumno, no inventa información, respeta abstención cuando no hay evidencia y queda dentro del presupuesto del caso.

| Etiqueta | Uso |
|---|---|
| `pass` | Cumple criterio principal y presupuesto. |
| `partial` | Ayuda, pero falta una pieza importante. |
| `fail` | No cumple el criterio principal. |
| `critical_failure` | Responde cuando debía abstenerse o rompe una condición de bloqueo. |
