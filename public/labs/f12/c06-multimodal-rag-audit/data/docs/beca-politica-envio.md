# Política de envío de becas 2026

## Sección 3.2. Envío de solicitud

La solicitud de beca solo puede enviarse cuando el justificante de matrícula aparece como validado en el sistema académico.

Si el justificante está pendiente de validación, el solicitante puede guardar el borrador y aportar documentación, pero no debe recibir una confirmación de envío definitivo.

## Sección 3.3. Evidencia mínima

Una respuesta automática debe citar la sección aplicada, el estado operativo consultado y la fecha de lectura del estado.
