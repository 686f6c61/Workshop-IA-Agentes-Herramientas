# Política sintética de becas

Versión: 2026-06-demo

La solicitud solo puede enviarse cuando el justificante de ingresos está subido en PDF y el estado operativo del expediente aparece como `documento_validado`.

Si el formulario muestra un botón bloqueado y el estado operativo es `validacion_pendiente`, el sistema debe informar de la causa probable y no prometer aprobación automática.

Si hay conflicto entre pantalla y estado operativo, la respuesta debe requerir revisión humana.
